# 🔓 ItsNowFree

**Paid software, reimagined. Free for everyone.**

ItsNowFree is an open-source organization from Pelotas, Brazil, dedicated to building free alternatives to paid software. We study how existing tools behave, document their functionality, and reimplement them from scratch, so anyone can use them without paying a license.

## What we do

- 🔍 **Analyze** the behavior and file formats of paid software
- 🛠️ **Rebuild** equivalent functionality with original, clean-room code
- 📖 **Document** everything openly so others can learn and contribute
- 🎁 **Release** it all under permissive open-source licenses

## Our principles

- **Original code only.** We never copy proprietary source code, assets, or branding.
- **Clean-room approach.** Behavior is documented first, implementation is written independently.
- **Open by default.** Public repos, public discussions, public roadmap.
- **Community first.** Useful software should be accessible to everyone, not only those who can afford it.

## Get involved

Pick an issue, suggest a tool we should replicate, or open a pull request. All skill levels are welcome.
